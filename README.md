Kila Turismo Website Preview

📋 Descrição
Site oficial da Kila Turismo, uma agência de viagens com 19 anos de experiência no mercado. Este website responsivo foi desenvolvido para conquistar novos clientes e apresentar os destinos turísticos oferecidos pela empresa.

✨ Funcionalidades
Design Responsivo: Experiência otimizada em dispositivos móveis, tablets e desktops
Apresentação de Destinos: Exibição atraente dos pacotes de viagem com preços e promoções
Galeria de Fotos: Compartilhamento de experiências reais dos clientes em suas viagens
Formulário de Contato: Comunicação direta com a equipe da Kila Turismo
Integração com WhatsApp: Botão de redirecionamento para atendimento rápido
Área Administrativa: Painel para gerenciamento de conteúdo (destinos, fotos, informações)

🚀 Como Executar o Projeto Localmente
Requisitos
Python 3.8+
pip (gerenciador de pacotes Python)
Instalação
Clone o repositório:

git clone https://github.com/seu-usuario/kila-turismo.git
cd kila-turismo
Instale as dependências:

pip install -r requirements.txt
Execute a aplicação:

python main.py
Acesse o site em seu navegador: http://localhost:5000
